# Roadmap

- **M1 — Stadium and character: implemented prototype.** Procedural recognizable park, consistent meter scale, colliders, daylight, player locomotion and camera. Next polish: authored reusable stadium props and more detailed field surfaces.
- **M2 — Drivable mower: implemented prototype.** Enter/exit, protected dismounts, arcade driving, reverse, braking, animated wheels and steering. Next polish: audio, seated character, handling tuning on Windows.
- **M3 — Grass mowing: implemented prototype.** Spatial cut mask, swept deck, direction shading, persistent session tracks and accurate unique-cell progress. Next polish: GPU performance validation and save/load.
- **M4 — Infield equipment and field tools: next feature milestone.** Start with one dragging tool, dirt condition mask, and a clear interaction loop. First finish a hands-on Windows acceptance pass for M1–M3.
- **M5 — Shifts, objectives, scoring: planned.** Timed preparation, finish quality, task scoring and a shift results panel.
- **M6 — Career progression: planned.** Equipment upgrades, multiple parks, unlocks and a groundskeeping career. Keep this outside the current prototype scope.
