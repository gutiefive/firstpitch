# Roadmap

- **M1 — Stadium and character: implemented prototype.** Procedural recognizable park, consistent meter scale, colliders, daylight, player locomotion and camera. First visual pass complete: covered stands, open dugouts, detailed workshop, community signs, infield lawn, textured dirt, and surrounding trees. Next polish: authored assets and a final Windows lighting pass.
- **M2 — Drivable mower: implemented prototype.** Enter/exit, protected dismounts, arcade driving, reverse, braking, animated wheels and steering. First visual pass adds treaded wheels, fenders, grille, and a visible seated groundskeeper. Next polish: audio and handling tuning on Windows.
- **M3 — Grass mowing: implemented prototype.** Spatial cut mask, swept deck, direction shading, persistent session tracks and accurate unique-cell progress. First visual pass adds mask-aware instanced grass tufts. Next polish: GPU performance validation and save/load.
- **M4 — Core field tools: implemented prototypes.** Tool-bay swapping between mower deck and tow-behind drag, lift/lower controls, visible rough-to-smooth dirt, unique-cell preparation score, protected grass/bases/mound/plate areas, and independent HUD objectives. A separate pushable chalk marker adds a paint gate, persistent real-position strokes, dashed foul-line guides, left/right unique-section coverage, and independent task selection. A hose station adds on-foot spray aiming, timed moisture accumulation, dark wet dirt, protected areas, reach/obstruction checks, and a fourth independent task. A fifth task uses a hand tamper to repair six worn mound patches through eighteen timed impacts, with a walkable mound slope and persistent patch state. Advanced clay handling, deformable terrain, and physically articulated tools remain future refinements.
- **M5 — Shifts, objectives, scoring: next milestone.** Timed preparation, finish quality, task scoring and a shift results panel.
- **M6 — Career progression: planned.** Equipment upgrades, multiple parks, unlocks and a groundskeeping career. Keep this outside the current prototype scope.
